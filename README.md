# brain-dump

## What it is

brain-dump is a small project kept in this repository. A fuller description of its purpose is pending confirmation from the author.

## Running the tests

Run the full test suite with one command:

```
npm test
```

This runs `node --test tests/` through the `test` script in package.json.

The six external settings are documented in [docs/CONFIG.md](docs/CONFIG.md). The operator supplies their values at runtime. No setting value is stored in this repository.
